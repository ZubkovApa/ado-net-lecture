# ADO.NET + PostgreSQL: примеры к лекции

Всё работает прямо в браузере: ничего устанавливать не нужно. Внутри уже есть .NET, PostgreSQL с базой `university` и пакет Npgsql.

## 1. Запуск

1. Войдите в свой аккаунт на [github.com](https://github.com) (нет аккаунта — зарегистрируйтесь, это бесплатно).
2. Откройте ссылку: **https://github.com/ZubkovApa/ado-net-lecture** и нажмите **Create codespace**.
3. Подождите 2–3 минуты, пока всё соберётся. Откроется редактор, похожий на Visual Studio, а в нём — файл `UniversityApp/Program.cs`.

Когда вернётесь в следующий раз, заходите через **github.com/codespaces**: там будет ваш уже созданный codespace со всеми изменениями.

## 2. Запуск примеров со слайдов

Все примеры уже лежат в `UniversityApp/Program.cs`, закомментированные и подписанные номером слайда.

1. Найдите нужный пример, например `// ===== Слайд 16: Создаём таблицы =====`.
2. Выделите его строки мышью и нажмите **Ctrl+/** — комментарии снимутся.
3. Внизу откройте терминал (если его нет: меню ☰ → Terminal → New Terminal) и выполните:
   ```
   cd UniversityApp
   dotnet run
   ```
4. Посмотрите результат. Затем снова выделите пример и нажмите **Ctrl+/**, чтобы закомментировать его обратно, и переходите к следующему.

Держите включённым **один пример за раз**. Иначе при каждом запуске будут заново выполняться и все предыдущие: например, в таблицу снова и снова добавятся одни и те же группы.

Рекомендуемый порядок для первого запуска: слайд 12 → 16 → 22–23 (заполнить базу) → дальше любые.

## 3. Как посмотреть, что лежит в базе

pgAdmin здесь нет, вместо него — команда `psql` в терминале. Откройте второй терминал (кнопка **+** в панели терминала) и введите:

```
psql
```

Вы сразу подключитесь к базе `university`. Полезные команды:

| Команда | Что делает |
|---|---|
| `\dt` | список таблиц |
| `SELECT * FROM groups;` | содержимое таблицы (точка с запятой обязательна) |
| `SELECT COUNT(*) FROM grades;` | сколько строк в таблице |
| `\q` | выйти из psql |

Можно и мышкой: слева иконка слона (расширение PostgreSQL) → добавить подключение: Server `localhost`, User `postgres`, Password `12345`, Database `university`.

## 4. Начать заново

Если данные запутались, включите пример со слайда 17 (удаление таблиц), запустите, затем снова слайды 16 и 22–23.

## 5. Приложение «Студенты»

Готовое консольное приложение со слайдов 45–46 лежит в папке `StudentsApp`. Перед запуском база должна быть заполнена (слайды 16 и 22–23).

```
cd StudentsApp
dotnet run
```

## Важно

- Codespace сам засыпает через 30 минут без активности. Все файлы при этом сохраняются.
- Бесплатного лимита GitHub хватает примерно на 60 часов работы в месяц. Закончили занятие — можно остановить codespace вручную на github.com/codespaces (⋯ → Stop codespace).
