# ADO.NET + PostgreSQL: практика к лекции

Всё работает прямо в браузере, ничего устанавливать не нужно. Внутри уже есть .NET, PostgreSQL с пустой базой `university` и пакет Npgsql.

## Запуск

1. Войдите в свой аккаунт на [github.com](https://github.com). Нет аккаунта — зарегистрируйтесь, это бесплатно.
2. Откройте ссылку **https://codespaces.new/ZubkovApa/ado-net-lecture** и нажмите **Create codespace**.
3. Подождите 2–3 минуты, пока всё соберётся. Откроется редактор, а в нём файлы `PRACTICE.md` и `UniversityApp/Program.cs`.

Дальше работайте по файлу **[PRACTICE.md](PRACTICE.md)**: там все шаги по порядку, код для вставки, ожидаемый результат каждого шага и в конце — проверка результата.

Когда вернётесь в следующий раз, заходите через **github.com/codespaces**: там будет ваш codespace со всеми изменениями и данными в базе.

## Что где лежит

| Папка или файл | Что это |
|---|---|
| `PRACTICE.md` | пошаговая практика |
| `UniversityApp/Program.cs` | сюда вставляете примеры |
| `StudentsApp/` | готовое приложение «Студенты» для последнего шага |
| `check.sh` | проверка: какие этапы пройдены |
| `RESULT.md` | появится после проверки |

## Важно

- Codespace сам засыпает через 30 минут без активности. Файлы и данные в базе при этом сохраняются.
- Codespace работает за счёт вашего бесплатного лимита GitHub (около 60 часов в месяц), его с запасом хватает на занятия. Закончили — остановите codespace на github.com/codespaces (⋯ → Stop codespace).
